# План на день первого контакта с планшетом

Всё делается на Windows в PowerShell из папки репо. `platform-tools` в папке репо находится сам, Path править не надо.

## 0. До подключения (5 минут)
1. Распакуй поверх с заменой `update-005`, `006`, `007` (если ещё не сделал).
2. `python .\\cappu.py check` -> в конце `All ... PASSED` и `mkadt_mt8176 self-test: OK`.
3. `python .\\cappu.py qemu` -> `QEMU result: PASS`.
4. `python .\\cappu.py doctor` -> `adb` и `fastboot` найдены.

## 1. Планшет
- Заряд 50% и выше (лучше 70+), Android загружен.
- Для разработчиков -> "Отладка по USB" включена. Подключи кабелем, на планшете подтверди ПК.

## 2. Собрать данные (только чтение, ничего не меняет)
1. `python .\\cappu.py report` с планшетом в Android. Создаст `report-*.txt`.
2. `adb reboot bootloader` (или Vol- + Power при включении).
3. Снова `python .\\cappu.py report`: второй файл, теперь с `fastboot getvar all` и `oem device-info`.
4. Пришли мне оба файла.

## 3. Решение по результатам (его принимаем вместе)
- `unlocked: true`: можно сразу к пункту 4.
- `unlocked: false`: нужна разблокировка через Mi Unlock (последний `miflash_unlock`, свой Mi-аккаунт, привязка в "Mi Unlock status"). Она стирает `userdata`. По посту 4PDA для Mi Pad 3 ждать 72 часа не нужно (пост 2017 года, не проверено).
- Бэкап нужных разделов: список имён будет в report (`partition names`). Команды для снятия подготовлю по нему. mtkclient для MT8176 не подтверждён, поэтому без моей проверки не запускай.

## 4. Первый запуск M1 (только после пункта 3)
1. `python .\\cappu.py tablet`. Скрипт сам: `adb devices`, проверка батареи, спросит про `adb reboot bootloader`, покажет `fastboot devices` и lock state, и только по слову `boot` выполнит `fastboot boot dist/m1-boot.img`.
2. Сразу фотографируй экран (результат держится 60 секунд, потом сам перезагрузится).
3. Пришли фото и вывод консоли.

## Если что-то не так
| Симптом | Что делать |
| --- | --- |
| `fastboot devices` пусто | другой порт/кабель, драйвер (Диспетчер устройств: неопознанное устройство), планшет точно в fastboot |
| `unauthorized` в adb | подтвердить запрос на планшете, отладка включена |
| `fastboot boot` отказал | безопасно, ничего не изменилось. Пробуй `fastboot boot dist\\m1-boot-raw.img`, потом пришли текст ошибки |
| Чёрный экран / завис | держи Power 10-15 секунд, он включится в Android |
| Планшет не включается вообще | не паникуй, ничего не прошивай, напиши мне |

## Чего НЕ делать
`fastboot flash`, `fastboot erase`, `fastboot -w`, `fastboot oem unlock` вручную, прошивать образы из `dist/`, ставить TWRP и стирать Android без бэкапа.
