## 6. Key finding of the last stretch: LSE
The Actions-built kernel contained 865 LSE instruction words (objdump 877) because MACHINE_FLAGS_ARM64_CAPPU was `-march=armv8.2-a+crypto` (inherited from the Snapdragon port) and commpage_asm.s has two unguarded `casa` (_pfz_trylock_and_enqueue/_dequeue); machine_routines_asm.s is already under `#if __ARM_ARCH_8_2__`. A Cortex-A72 would take an undefined-instruction exception at the first atomic. Patch 0083: `-march=armv8-a+crypto` + ldaxr/stxr fallback (V: fallback assembles under -march=armv8-a with clang; plain casa is rejected there). NOT verified: the full XNU build with the new flag (needs the Actions runner): the user must push and report the run of the `xnu` workflow; green = no LSE left. Also crypto: whether the MT8176 core has the crypto extension is U (M1 prints ISAR0). ## 8. Brick-safety rules (mipad3/docs/brick-safety.md)
Never write preloader/boot0/boot1/lk. Only `fastboot boot` (RAM, writes nothing) for tests. Install only into userdata later. Full backup of the needed partitions BEFORE any write. Never use fastboot flash/erase/-w/oem unlock by hand before backup. Hang recovery: hold Power 10-15 s; Vol- + Power = fastboot; M1 also resets itself after 60 s via PSCI (U that PSCI reset works here). If LK is locked, `fastboot boot` refuses = safe outcome.
